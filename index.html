03 — Practice

How the work is actually done.

The contract before the polish

When a React screen and a Laravel API disagree, the user feels a broken page. The resource is named the way the product talks about it. Errors are something the interface can act on. The payload stays as small as the screen needs.

One owner, three layers

Business rules live in Laravel and PHP. The person meets the product in React. Node.js and Socket.IO step in when something has to move in real time. MySQL or MongoDB is a choice about the data, not a badge.

AI next to the stack

OpenAI is used inside real products — structured outputs, faster drafts, stricter reviews. It does not replace reading the schema or the interface before something is called done.
